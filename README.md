# Interactive Personal Portfolio Website

## Project Overview

This project is an Interactive Personal Portfolio Website developed using **HTML5, CSS3, and JavaScript** as part of the **Week 3 Web Development Internship**. The website showcases personal information, technical skills, projects, and a contact form with interactive JavaScript features. It provides a responsive and user-friendly interface across different screen sizes.

---

## Features

- Responsive website design
- Navigation menu
- About Me section
- Technical Skills section
- Projects section
- Contact form
- Form validation with error messages
- Dark/Light mode toggle
- Random motivational quote generator
- Real-time input validation
- Local Storage support
- Hover effects and smooth transitions

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server**.
5. The website will open in your default browser.

---

## Interactive Features

### 1. Form Validation
- Validates Name, Email, and Message fields.
- Displays appropriate error messages.
- Shows a success message after successful validation.

### 2. Dark Mode
- Allows users to switch between Light and Dark themes.
- Saves the selected theme using Local Storage.

### 3. Random Quote Generator
- Displays a different motivational quote each time the button is clicked.

### 4. Real-Time Validation
- Removes error messages as the user enters valid input.
